# Yavaş Çay Demleyici

## Bu Ne?

Bu, dünyanın en yavaş, en abartılı ve en gereksiz çay demleme simülatörüdür. 

Gerçekten çalışır. Python ile yazılmıştır. Hiçbir şey yapmaz ama yapar gibi görünür. 

## Neden Var?

Çünkü aklıma takıldı. Ve çünkü GitHub'da yer var. 

Bu repo, zamanınızı boşa harcamanız için özel olarak tasarlanmıştır. 

## Nasıl Kullanılır?

```bash
python cay_demle.py
```

Kaç bardak istediğinizi sorar. Cevap verin. Bekleyin. Çok bekleyin.

## Özellikler

- Gerçekten yavaş
- Abartılı mesajlar
- Rastgele "çay düşüncelere daldı" olayları
- Hiçbir şey üretmez
- Çayı soğutur (simülasyon)

## Uyarı

Bu kodu üretimde kullanmayın. Çayınızı gerçekten demlemek için çaydanlık kullanın.

## Lisans

Yok. Kullanın, bozun, silin. Umurumda değil.
